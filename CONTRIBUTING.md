# Contributing to Jolly Open

Thank you for helping improve menstrual health for girls and women across Africa.

## Ways to contribute

- **Developers**: improve the data standard, build integrations, report bugs
- **Clinicians and researchers**: review pain scales, symptom lists and red-flag criteria
- **Health programmes and schools**: tell us what data you need and how you would use it
- **Translators**: help make Botsolai content available in local languages

## How to contribute

1. Open an **issue** describing the problem or idea.
2. Fork the repository and create a branch.
3. Make your changes and confirm all examples still validate against the schema.
4. Open a **pull request** that references the issue.

## Ground rules

- **Never commit real user data**, even anonymised samples. Use synthetic examples only.
- Changes to the data standard must keep it privacy-first: no direct identifiers, no free-text fields.
- Be respectful. Menstrual health is still stigmatised; keep discussions inclusive and kind.
